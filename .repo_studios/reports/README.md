# Repo Studios Report Layout

<!-- markdownlint-disable MD013 -->

This directory now mirrors the producer → consumer → aggregator → orchestrator → summarizer → utility flow used by the active scripts under `.repo_studios/scripts/`. Each subfolder is pre-created so refactored automation can land artifacts in predictable locations without having to recreate directory scaffolding at runtime.

## Top-Level Folders

| Folder | Artifact Focus | Notes |
| --- | --- | --- |
| `producer_reports/` | Raw data extracts emitted by producer scripts (inventory snapshots, standards indices, static analysis checks). | Subfolders end in `_reports` to highlight the canonical artifact name. |
| `consumer_reports/` | Single-hop analyses derived from one producer feed (anchor health, fault artifacts, test log health). | Use these paths when re-enabling consumer scripts so the outputs stay colocated with their inputs. |
| `aggregator_reports/` | Multi-source rollups that blend several producer/consumer artifacts, such as monkey patch trends and churn/complexity heatmaps. | Intentionally paired with the aggregator tier to clarify dependencies. |
| `manifest_reports/` | Manifest-style exports that describe the active script suite or standards metadata. | Reserve for YAML/JSON indices that agents will ingest. |
| `summarizer_reports/` | Executive-level summaries and condensed narratives that summarizer scripts produce. | Ideal for artifacts that agents hand off to stakeholders. |
| `utility_logs/` | Supporting logs and baselines generated by utilities (faulthandler helpers, mypy baseline refreshes, etc.). | Combines routine diagnostic logs and baseline refresh outputs. |
| `docs/`, `scripts/`, `summary/`, `tests/` | Pre-existing report spaces retained for historical content. | Future migration tasks will reconcile or archive these as needed. |

## Folder Details

### producer_reports/

- `standards_index_reports/` – canonical `repo_standards_index.yaml` snapshots and related diffs.
- `standards_diff_reports/` – delta views between index revisions for CI guardrails.
- `standards_gap_reports/` – gap analyses highlighting directives missing from the standards index.
- `anchor_inventory_reports/` – anchor inventories and duplicate slug diagnostics.
- `standards_prompt_reports/` – prompt seed bundles exported for AI consumption.
- `dependency_hygiene_reports/` – dependency audit findings (pins, duplicates, VCS refs).
- `import_graph_reports/` – module graph JSON/markdown outputs from topology scans.
- `lizard_metrics_reports/` – complexity reports emitted by `generate_lizard_report.py`; each run now includes a ranked top-10 offender table (path, line, delta over thresholds, recommended remediation) alongside JSON/log artifacts for planning manual extractions.
- `typecheck_reports/` – mypy error snapshots and summaries.
- `test_coverage_reports/` – function coverage inventories sourced from Coverage.py XML, including uncovered function lists for each module.
- `monkey_patch_scan_reports/` – raw inventory of monkey patches prior to risk classification.
- `placeholder_scan_reports/` – TODO/FIXME placeholder scans for hygiene dashboards.
- `inventory_health_reports/` – aggregated inventory health summaries.
- `inventory_view_reports/` – rendered inventory views (YAML, Markdown).
- `inventory_validation_reports/` – validation results from schema checks.
- `docs_integrity_reports/` – documentation integrity/verifier outputs.
- `metrics_anchor_stub_reports/` – checks for missing metrics anchor stubs in orchestrator docs.
- `markdown_anchor_validation_reports/` – markdown anchor validation outputs.

### consumer_reports/

- `monkey_patch_risk_reports/` – risk classifications produced after scanning monkey patches.
- `anchor_health_reports/` – duplicate anchor health scorecards.
- `fault_artifact_reports/` – faulthandler artifact bundles (CSV, JSON, Markdown).
- `test_log_health_reports/` – pytest log health bundles (JSON/Markdown/CSV) with warnings,
  slow-test tables, and pass-rate delta metadata.

### aggregator_reports/

- `monkey_patch_trends_reports/` – trend deltas across monkey-patch inventories.
- `churn_complexity_heatmap_reports/` – churn vs. complexity heatmaps for hotspot triage.

### manifest_reports/

- `standards_manifest_reports/` – standards-focused manifest exports for partner teams.
- `scripts_manifest_reports/` – migration manifests and suite catalogs for automation coverage.

### summarizer_reports/

- `health_suite_summary_reports/` – executive summaries of cross-suite health signals.
- `standards_summary_reports/` – standards telemetry summaries for leadership briefings.

### utility_logs/

- `faulthandler_snapshot_logs/` – ad-hoc faulthandler thread dumps and captures.
- `faulthandler_runtime_logs/` – runtime configuration logs from the faulthandler sitecustomize shim.
