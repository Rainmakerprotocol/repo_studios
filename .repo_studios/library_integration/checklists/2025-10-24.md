## Outstanding Considerations

1. **Library Structure Diff** – Need detailed comparison between generated structure and existing Repo Studios directories to avoid clashes; any reconciliation must preserve AI-friendly naming and navigation conventions.
2. **Schema Compatibility** – Existing folder-level index/analyzer workflow stays in place; a new duplicate-focused script will operate at repo scope using library-aware reporting. No tight coupling required, but we must document how the two data sets complement each other and create the hand-off loop (you notify duplicates, agent checks library/docs, extracts, tests, and updates callers).
3. **Testing Footprint** – Library tests will live alongside the library in a mirrored branch structure (per reference bundle). Confirm fixture needs and ensure the mirrored layout meshes with current test runners.
4. **Tooling Cross-Platform** – Manual scripts and test commands must succeed on Windows, Linux, and macOS; add validation steps for each target shell.
5. **Governance Alignment** – Single approver confirmed (you). Capture this in rollout notes so future contributors know who signs off.
6. **Report Retention & Pruning** – Establish how many historical run folders to keep in `.repo_studios/library_integration/reports/` and when to prune (minimum one run retained; recommend no more than three for balance). Document policy in protocol README once approved.
