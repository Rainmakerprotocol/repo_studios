## Migration Notices (2025-12-05)

- Legacy aliases (`studio-run-fault-pipeline`, `studio-run-standards-gap-suite`) remain callable but
  start emitting deprecation banners on 2025-12-12; see
  `docs/automation/orchestrator_migration_announcement.md` for the full retirement calendar.
- Direct script invocations (`orchestrate_health_suite.py`, `run_pytest_log_capture.py`) already
  forward into their topic counterparts; plan removals once telemetry confirms zero legacy usage
  after 2026-01-16.
- Update runbooks and prompt references to point at `studio-orchestrate-<topic>` and
  `studio-orchestrate-full-diagnostic` before the warning window opens.

## Notes

- The command center Make target (`make -C .repo_studios command-center COMMAND_CENTER_TARGET=<path>`) now sits alongside
  `studio-orchestrate-fault-diagnostics` and `studio-orchestrate-docs-health`; remaining orchestrators still require manual invocation until their dedicated Make targets are added.
- Update this table whenever Make targets or CI hooks change so the script inventory can reference the latest wiring
  before orchestrator refactors proceed.
