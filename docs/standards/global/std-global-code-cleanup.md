## Incremental Workflows

- Structure cleanup efforts as small, reviewable changesets to reduce merge conflicts and reviewer fatigue.
- Capture rationale for each cleanup task in the pull request description so future work can build on the context.
- Prefer automated formatting and linting fixes as separate commits when practical to keep code changes clear.
